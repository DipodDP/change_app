# Change

[English](README.md) · Русский

Находит самый выгодный способ обменять валюту через цепочки обменов, которые
вы действительно совершали, а не по биржевым курсам.

Вы записываете реальные обмены — сколько отдали, сколько получили и в каком
банке. Фактический курс (с уже включённой комиссией) получается из этих двух
сумм. Change считает каждый обмен ребром графа и находит все цепочки между
двумя валютами, упорядоченные по тому, сколько вы в итоге получите.

## Пример

Записаны такие обмены:

| Отдали | Получили | Банк | |
|---|---|---|---|
| 60 000 RUB | 2 140.43 BYN | Белинвестбанк | |
| 100 BYN | 28.84 EUR | Приорбанк | |
| 28.84 EUR | 28.70 EUR | Приорбанк → OTP | перевод |
| 14.02 EUR | 5 000 HUF | OTP | |
| 100 BYN | 33.26 USD | Freedom | |
| 33.26 USD | 32.60 USD | Freedom → Wise | перевод |
| 7.34 USD | 2 200 HUF | Wise | |

Сравнение 100 BYN → HUF:

| Маршрут | Итог | |
|---|---|---|
| BYN → EUR → HUF, через Приорбанк и OTP | **10 235.38 HUF** | лучший курс |
| BYN → USD → HUF, через Freedom и Wise | 9 771.12 HUF | −4.54% |

Маршрут через евро выгоднее на 464.26 HUF на каждые 100 BYN. RUB → HUF
строится автоматически через BYN — вводить его как маршрут не нужно.

Цепочка продолжается только там, где лежат деньги: остаток в одном банке нельзя
потратить в другом. Деньги между банками переносят две строки-перевода — без
них это семь несвязанных обменов, и маршрута между ними нет. Внесение
наличных записывается так же — перевод в той же валюте из «Наличные» в банк.

## Аккаунты

Всё работает без входа. Обмены, записанные без входа, принадлежат браузеру и
хранятся, пока он заходит хотя бы раз в 30 дней. Регистрация (почта и пароль)
переносит их в аккаунт — там они хранятся всегда и доступны с любого
устройства.

## Запуск

Зависимости управляются через [uv](https://docs.astral.sh/uv/); `uv run` сам
создаёт и синхронизирует окружение, активировать его не нужно.

    uv run python manage.py migrate
    uv run python manage.py compilemessages -l ru -l en
    uv run python manage.py createsuperuser        # для /admin/
    uv run python manage.py runserver

Затем откройте http://127.0.0.1:8000. Переводы — собираемые файлы и не хранятся
в репозитории, поэтому нужен шаг `compilemessages`.

Чтобы открыть приложение в локальной сети или tailnet, слушайте все интерфейсы
и добавьте адрес в `ALLOWED_HOSTS` / `CSRF_TRUSTED_ORIGINS` в
`config/settings.py`:

    uv run python manage.py runserver 0.0.0.0:8000

Обмены без входа остаются в базе и после истечения сессии, пока их не
удалить. Запускайте ежедневно:

    uv run python manage.py clearsessions && uv run python manage.py purge_guests

Вне разработки задайте `DJANGO_SECRET_KEY` и `DJANGO_DEBUG=0`.

## Заметки

- **Деньги** округляются до 2 знаков банковским округлением
  (`ROUND_HALF_EVEN`) — см. `exchanges/money.py`. Курсы в расчётах не
  округляются, только при показе.
- **Курсы исторические.** Они взяты из уже совершённых обменов и отвечают на
  вопрос «какой путь был дешевле», а не «сколько это стоит сейчас». В маршрутах
  участвует только последняя запись для каждой пары валют и банка; более старые
  остаются в истории.
- **Маршруты** находятся поиском по графу всех записанных обменов и не выходят
  за пределы банка, если деньги не перенесены переводом. Маршрут может
  заканчиваться переводом, поэтому «EUR наличными» и «EUR, внесённые в банк» —
  разные варианты.
- **Языки**: английский и русский, переключаются в шапке.
